# 보스 러시 / Boss Rush (가칭) — 기획서

> 결정 008. 이전 쇠공 기획은 태그 `wrecker-poc`(결정 001~007).

## 한 줄
매주 새 거대 보스가 오는 세로 탄막 슈팅. 보스의 부위(장갑 → 포대 → 핵)가 떨어져 나갈 때마다 단계가 바뀌고, 보스마다 짧은 이야기가 붙어 한 달에 한 막이 완성된다.

## 차별점(결정 009) — 「오늘의 보스」 + 「해체 쾌감」
우주 슈팅 겉모습만으로는 차별이 안 된다는 평가("A급도 C급도 아닌 애매한 포지션")에 따라 켜자마자 느끼는 차별점 둘을 앞세운다. 매주 새 보스·AI 콘텐츠 공장은 뒤에서 받치는 구조로 유지.
- **A. 오늘의 보스**: 하루 하나, 전 세계 같은 보스. 날짜 씨앗으로 결정적 생성(서버 없이 배포). 판수 제한 없이 최고 기록, 공유 카드.
- **C. 해체 쾌감**: 쏜 자리대로 보스 선체의 장갑 타일이 벗겨지고 속 기계가 빛나며 드러남. 판마다 부서진 모양이 다름.
- 제외: Game Center·Play 게임즈 순위표(플랫폼별로 갈려 전 세계 순위가 안 됨). 3D 화면(View3D)은 유지.

### 단계별 연동
| 단계 | 내용 | 서버 |
|---|---|---|
| 1 | 날짜 씨앗 보스, 해체 표현, 기기 내 최고 기록, 결과 카드. **실기기로 재미 판정 먼저** | 없음 |
| 2 | Firebase 익명 로그인 + 오늘의 순위표(REST API를 `HTTPRequest`로, 플러그인 없이), 점수 상한 검사 | Firebase |
| 3 | Apple·Google 계정 연결(link), 다 같이 잡는 주간 보스(B안), 리플레이 점수 검증 | Firebase |

주의: Google 로그인을 넣으면 Apple 로그인도 요구됨 / 계정 생성 시 앱 안 계정 삭제 의무 / 개인정보 처리방침 갱신 / Firebase 프로젝트는 개인 사이트와 분리해 새로 만들고 생성은 사용자 확인 뒤 / Cloud Functions는 Blaze 요금제 필요.

## 첫 10초(결정 007 기준)
1. 켜자마자 「WARNING」 경보·붉은 섬광·화면 흔들림, 보스가 위에서 내려와 화면을 채움. 이름 카드 「1주차 강철 고래 — 구름 아래서 떠오른 첫 번째 거신」.
2. 기체는 손가락 움직임을 그대로 따라감(관성 없음, 손가락보다 1.3배). 사격은 자동, 쉬지 않음.
3. 2~3초 안에 첫 장갑이 깨짐: 히트스톱·흰 섬광·충격파 고리·파편·폭발·튀는 숫자·빨려 드는 보석·진동.
4. 장갑이 다 깨지면 「2단계!」, 화면의 적탄이 모두 보석으로 바뀜(쾌감 + 숨 돌릴 틈).

## 규칙(PoC)
- 목숨 3, 맞으면 2초 무적 + 주변 적탄 지움. 판정은 기체 가운데 빛나는 점(반지름 7).
- 부위는 자기 단계일 때만 맞음(아니면 튕기는 불꽃). 핵이 부서지면 격파.
- 보스·패턴은 데이터 `content/bosses/<id>.json`(부위: group·phase·shape·x·y·r·hp / 단계별 패턴: fan·ring·spiral, from·speed·every·color…).

## AI 콘텐츠 공장(목표 구조)
- AI가 매주 보스 1종(부위 배치·패턴·이름·한·영 이야기)을 데이터로 씀 → 자동 검사기(필드·단계·가려진 부위·화면 범위·동시 탄 수, 검수 담당 목록은 `docs/HANDOFF.md`) → 봇이 회피 가능성·실력 단계별 클리어율 판정 → 사람은 새 보스를 3판 해 보고 "시원한가"만 판단.

## 그림
- 처음 코드로 그은 선·다각형은 **사용자 판정 "허접해 보임"**. 이후 3D 화면(View3D: 판정은 2D 그대로, 광선-평면 교차로 3D 위치 맞춤)으로 옮겼고 유지한다(결정 009). 해체 쾌감(장갑 타일이 벗겨지며 속 기계가 빛남)이 이 그림의 핵심 볼거리.

## 수익(후속)
보상형 광고(이어하기·일일 도전권) + 광고 제거 + 확률 없는 시즌 패스(무료/유료 줄, 새 보스·기체 꾸미기). 뽑기 없음.
