## 환경
- `brew install --cask godot`(4.7.2), 내보내기 템플릿은 GitHub 릴리스에서 받아 설치, `openjdk@17`(temurin은 관리자 암호 필요로 실패). Godot가 SDK·JDK(openjdk@21)·디버그 키를 자동 설정.
- Kenney 팩은 페이지의 서명 링크(사이트 쿠키 필요)를 인앱 브라우저에서 받아 내려받음. 7팩 `License.txt` 모두 CC0.

## PoC 구현
- 장면을 코드로 짓는 구조(`scripts/main.gd`). 블록 건물 MultiMesh 1개 + 파편 MultiMesh 1개.
- 첫 봇 판: 23초에 파괴율 60%로 승리(너무 쉬움), 체력 99로 끝(경찰 위협 약함).
- 화면 확인으로 고친 것: 쇠공이 하얗게 보임(최고 속도면 늘 흰 쇠였음 → 최고 속도의 60%부터 천천히 달아오르게), 창문 불빛이 흰 노랑(발광 2.4 → 1.25, 더 주황), 가로등 불빛 웅덩이가 소용돌이 무늬(그림 대신 코드 원형 그러데이션), 쇠공이 잔해에 묻힘(바닥 주황 빛 고리, 카메라를 더 위에서).
- GDScript 주의: 여러 줄 람다를 인자 중간에 쓰면 해석이 애매해 사전·이름 있는 함수로 바꿈. Packed 배열은 for 루프에서 값 복사라 `resize`가 원본에 안 먹음.
